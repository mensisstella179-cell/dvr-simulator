Buka di browser atau pasang sebagai aplikasi

Tanpa unduhan. Berjalan di Android, Windows, iPhone, dan Mac. Setelah dibuka sekali, bisa dipakai tanpa internet.

  1. Android: buka di Chrome → menu ⋮ → Instal aplikasi
  2. Windows: buka di Chrome/Edge → klik ikon instal di kotak alamat
  3. iPhone: buka di Safari → Bagikan → Tambah ke Layar Utama

Pintasan Windows

Berkas kecil yang membuka simulasi di jendela aplikasi (Edge atau Chrome). Tanpa instalasi dan tanpa internet.

  1. Unduh berkas zip di bawah
  2. Klik kanan → Extract All
  3. Klik dua kali Buka-DVR-Simulator.bat

Aplikasi desktop (.exe)

Aplikasi mandiri berbasis Python. Kadang diblokir antivirus atau gagal di komputer tertentu. Jika bermasalah, pakai Cara 1 atau 2.

  1. Unduh zip, lalu Extract All
  2. Jalankan DVRSimulator.exe di dalam folder
  3. Jika muncul peringatan: More info → Run anyway

Bantuan jika unduhan tidak berjalan
  • Unduhan hanya tersedia jika pemilik sudah mengunggah berkasnya ke halaman Rilis. Jika muncul "404", gunakan Cara 1.
  • Windows Defender memblokir berkas? Buka Windows Security → Virus & threat protection → Protection history → Allow on device.
  • Tombol instal tidak muncul di Android? Pastikan memakai Chrome dan membuka lewat alamat https://.
Tentang simulasi ini

Simulasi edukatif: DVR dimodelkan sebagai sumber tegangan seri ideal dengan batas tegangan, kVA, arus, dan energi DC. Mencakup sag, swell, dan interupsi, gangguan 3 fasa, antar fasa, dan 1 fasa–tanah, 11 skenario, uji otomatis, dan laporan otomatis. Inverter, trafo injeksi, rugi-rugi, PLL, dan switching tidak dimodelkan. Bukan alat desain sistem nyata.
